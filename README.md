## Java Product Inventory Database
Simple Java program that integrates with a SQLite database to create a product inventory system.

### Instructions
Open the project folder in the terminal and run the following commands:  
`javac -cp ".:lib/sqlite-jdbc-3.54.1.0.jar" Main.java`  
`java  -cp ".:lib/sqlite-jdbc-3.54.1.0.jar" Main`  
This will compile and run the program with the JDBC driver which is included in the `lib` folder.
